# Portlight

Portlight brings selected remote screens into one uncluttered window. The publisher signature is **by Studio Upgrade**; it belongs in Connections and About, not over the remote picture.

The original mark combines overlapping windows and a pointer, with a warm light passing through the front window. It uses Studio Upgrade's sunflower `#FFC310`, fire `#FF6238`, plum `#930A3E`, and warm white `#F7F1E8`. Interface surfaces use system appearance rather than fixed brand-colored backgrounds.

- `Portlight.svg`: editable vector artwork.
- `Portlight.png`: high-resolution application/connection artwork.
- `Portlight.icns`: macOS app icon.
- `Portlight.ico`: Windows icon containing 16–256 pixel images.
- `build.sh`: rebuilds platform assets from deterministic vector drawing code.

These original project assets are provided under the repository's MIT license. The product name is a working name, not a claim of exclusive ownership of the word. No Apple font or SF Symbol artwork is redistributed for Windows.
